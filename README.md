# 📱 Termux Automation Setup

An automated setup script designed to transform a fresh Termux installation into a fully-configured, developer-friendly, and media-ready environment within minutes.

---

## ✨ Features

- **System Upgrades:** Automatically updates and upgrades all core Termux packages.
- **Storage Integration:** Quickly requests and sets up shared storage access.
- **Modern Shell Environment:** Installs **Zsh** powered by **Oh My Zsh** for an enhanced CLI experience.
- **Multi-Device Music Streaming:** Sets up **MPD (Music Player Daemon)**, `ncmpcpp`, and `PulseAudio`, configured to accept remote connections so you can play and control music across multiple devices.
- **Service Daemon Management:** Utilizes `termux-services` to manage background background processes smoothly.
- **Developer Editors:** Installs essential text editors like **Nano** and **Vim**.
